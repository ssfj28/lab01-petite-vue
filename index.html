Преломление света

Что такое преломление света?

Преломление света — это изменение направления распространения светового луча при переходе из одной среды в другую.

При переходе через границу двух сред скорость распространения света изменяется, вследствие чего изменяется направление его распространения.

Закон преломления света

Закон Снеллиуса:

n₁ · sin(θ₁) = n₂ · sin(θ₂)

где:

  • n₁ — показатель преломления первой среды;
  • n₂ — показатель преломления второй среды;
  • θ₁ — угол падения;
  • θ₂ — угол преломления;

Угол преломления можно определить по формуле:

θ₂ = arcsin((n₁ · sin(θ₁)) / n₂)

Показатель преломления

Показатель преломления характеризует оптические свойства среды и связан со скоростью распространения света в этой среде.

n = c / v

  • n — показатель преломления;
  • c — скорость света в вакууме;
  • v — скорость света в среде;
